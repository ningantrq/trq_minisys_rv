## 模块功能
Decode模块是流水线的第二级（ID级），负责：
1. 提取寄存器地址（rs1, rs2, rd）
2. 提取和扩展立即数（I/S/B/U/J五种格式）
3. 识别指令类型（是否需要访存、乘除法、CSR等）
4. 生成控制信号（是否写回寄存器、是否有效指令等）

全部是组合逻辑，无延迟！

### 控制信号的作用

| 信号 | 作用 | 使用者 |
|------|------|--------|
| `lsu_o` | 需要访存单元 | Pipeline Ctrl (暂停检测) |
| `mem_read_o` | 内存读 | LSU (生成读信号) |
| `mem_write_o` | 内存写 | LSU (生成写信号) |
| `mul_o` | 乘法指令 | Pipeline Ctrl (使能乘法器) |
| `div_o` | 除法指令 | Pipeline Ctrl (使能除法器) |
| `csr_o` | CSR/特权指令 | CSR模块 |
| `rd_valid_o` | 写回有效 | Pipeline Ctrl (数据冒险检测) |
