## 模块功能

Fetch模块是流水线的第一级（IF级），负责：
1. 维护程序计数器（PC）
2. 从指令内存读取指令
3. 处理分支跳转
4. 生成暂停信号（等待内存响应时）

## 设计要点

### **1. PC的更新逻辑**
```
正常情况: PC = PC + 4        (顺序执行下一条指令)
分支情况: PC = branch_target (跳转到目标地址)
复位情况: PC = 0x80000000    (RISC-V规范的起始地址)
```

### **2. 为什么是0x80000000？**
- RISC-V约定：机器模式代码从`0x80000000`开始
- 低地址（0x00000000-0x7FFFFFFF）保留给外设和ROM
- 这是一个虚拟地址，由MMU映射到物理内存

### **3. 状态机设计**
```
IDLE状态: 
  - 等待enable信号
  - enable到来时更新PC并请求内存

WAIT状态:
  - 等待内存响应（mem_done_i）
  - 产生stall信号暂停后续流水线
  - 收到数据后返回IDLE
```

### **4. 与内存接口的握手**
```verilog
CPU侧:
  mem_enable_o = 1  // 发起请求
  mem_addr_o = PC   // 提供地址

内存侧:
  mem_done_i = 1    // 数据准备好
  mem_data_i = inst // 返回指令
```
