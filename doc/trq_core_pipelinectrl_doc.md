## 模块概述

**核心职责**：
1. **流水线寄存器**：维护IF/ID、ID/EX、EX/MEM、MEM/WB四级寄存器
2. **冒险检测**：识别数据冒险（Load-Use）和控制冒险（分支）
3. **数据前递**：将EX/MEM/WB的结果前递到EX，避免stall
4. **暂停控制**：处理LSU、乘除法、内存访问等长延迟指令
5. **气泡插入**：清空流水线以处理分支跳转

**设计规模**：约356行代码，~130个寄存器信号，是CPU中最复杂的模块。

## 核心职责

### **1. 流水线寄存器分布**

```
IF → [IF/ID] → ID → [ID/EX] → EX → [EX/MEM] → MEM → [MEM/WB] → WB
```

每级寄存器保存：
- **IF/ID**: pc, inst
- **ID/EX**: pc, inst, rs1/rs2数据, 立即数, 控制信号
- **EX/MEM**: pc, inst, ALU结果, rs2数据, rd地址, 控制信号
- **MEM/WB**: rd地址, rd数据

### **2. 数据冒险类型**

| 冒险类型 | 解决方案 | 延迟 |
|---------|---------|------|
| **EX冒险** | EX→EX前递 | 0周期 |
| **MEM冒险** | MEM→EX前递 | 0周期 |
| **Load-Use** | 暂停1周期 | 1周期 |

### **3. 控制冒险**

```
分支跳转 → 清空IF/ID → 插入2个气泡 → 损失2周期
```
