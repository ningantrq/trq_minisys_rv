### **1. 双端口读，单端口写**
```
        ┌─────────────────┐
ra ────→│                 │────→ ra_data (读端口A)
rb ────→│   Regfile       │────→ rb_data (读端口B)
rd ────→│   (32 × 32bit)  │
rd_data→│                 │
        └─────────────────┘
```
- **同时读取2个寄存器**：大多数指令需要2个源操作数（如ADD x3, x1, x2）
- **写入1个寄存器**：每条指令最多写1个目标寄存器
