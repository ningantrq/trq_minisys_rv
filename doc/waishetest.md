# PWM控制器和看门狗测试方案

## 1. 测试目标

本测试方案旨在验证MiniSys RISC-V系统中新增的PWM控制器和看门狗外设的功能正确性和稳定性。测试将覆盖以下方面：

### 1.1 PWM控制器测试目标
- 验证4路PWM输出的基本功能
- 验证周期和占空比配置的正确性
- 验证通道独立使能/禁用功能
- 验证寄存器读写操作的正确性

### 1.2 看门狗测试目标
- 验证看门狗计时功能的正确性
- 验证中断产生机制
- 验证系统复位功能
- 验证寄存器读写操作的正确性
- 验证自动重载功能

## 2. 测试环境

### 2.1 硬件环境
- MiniSys RISC-V开发板或FPGA验证平台
- 示波器（用于观察PWM波形）
- 逻辑分析仪（可选，用于详细时序分析）
- UART通信接口（用于输出测试结果）

### 2.2 软件环境
- Verilog仿真工具（如ModelSim、Vivado Simulator）
- RISC-V交叉编译工具链
- MiniSys系统固件
- 测试用例程序

## 3. 测试工具

1. **仿真工具**：用于功能验证和时序分析
2. **示波器**：用于测量PWM输出的周期和占空比
3. **UART终端**：用于接收测试程序的输出信息
4. **交叉编译器**：用于编译RISC-V测试程序

## 5. 测试步骤

### 5.1 仿真测试步骤

1. **准备测试环境**
   - 安装并配置Verilog仿真工具
   - 编译MiniSys系统代码，包括新增的PWM和看门狗模块

2. **运行功能仿真**
   - 加载测试激励文件
   - 运行仿真，观察内部信号和输出端口
   - 验证PWM波形的周期和占空比
   - 验证看门狗的计时和中断/复位功能

3. **时序分析**
   - 检查关键路径的时序是否满足要求
   - 验证寄存器访问的时序正确性

### 5.2 硬件测试步骤

1. **准备测试环境**
   - 搭建MiniSys RISC-V开发平台
   - 连接示波器到PWM输出端口
   - 连接UART线缆用于通信

2. **下载测试程序**
   - 编译测试用例程序
   - 通过JTAG或其他方式下载到开发板

3. **执行测试用例**
   - 按照测试用例步骤执行操作
   - 使用示波器观察PWM输出波形
   - 通过UART终端查看测试结果
   - 记录测试数据

4. **结果分析**
   - 比较实际测试结果与预期结果
   - 分析偏差原因
   - 生成测试报告

### 6.3 仿真测试预期结果

#### 6.3.1 PWM控制器仿真测试预期结果

使用`test_peri_pwm.v`进行仿真测试时，预期会观察到以下结果：

1. **测试1: 寄存器写操作**
   - 控制台输出：`测试1: 寄存器写操作`
   - 周期寄存器被设置为100（2us）
   - 各通道占空比被设置为不同值
   - 控制寄存器被设置为0x1F（使能所有通道）

2. **测试2: 寄存器读操作**
   - 控制台输出：`测试2: 寄存器读操作`
   - 周期寄存器值：100
   - 通道0占空比寄存器值：50
   - 控制寄存器值：0x1F

3. **测试3: 观察PWM波形**
   - 控制台输出：`测试3: 观察PWM波形`
   - PWM0输出：50%占空比，周期2us的方波
   - PWM1输出：25%占空比，周期2us的方波
   - PWM2输出：75%占空比，周期2us的方波
   - PWM3输出：10%占空比，周期2us的方波

4. **测试4: 动态修改占空比**
   - 控制台输出：`测试4: 动态修改占空比`
   - 通道0占空比被修改为80%
   - PWM0波形占空比变为80%

5. **测试5: 关闭PWM**
   - 控制台输出：`测试5: 关闭PWM`
   - 所有PWM输出变为低电平

**波形观察要点：**
- PWM0：高电平1us，低电平1us（50%占空比）
- PWM1：高电平0.5us，低电平1.5us（25%占空比）
- PWM2：高电平1.5us，低电平0.5us（75%占空比）
- PWM3：高电平0.2us，低电平1.8us（10%占空比）

#### 6.3.2 看门狗仿真测试预期结果

使用`test_peri_watchdog.v`进行仿真测试时，预期会观察到以下结果：

1. **测试1: 寄存器写操作**
   - 控制台输出：`测试1: 寄存器写操作`
   - 超时时间寄存器被设置为5（5ms）
   - 控制寄存器被设置为0x0F（使能+中断+复位+自动重载）

2. **测试2: 寄存器读操作**
   - 控制台输出：`测试2: 寄存器读操作`
   - 超时时间寄存器值：5
   - 控制寄存器值：0x0F
   - 状态寄存器值：0x02（看门狗激活）

3. **测试3: 看门狗超时中断测试**
   - 控制台输出：`测试3: 看门狗超时中断测试`
   - 约5ms时产生中断：`*: 产生看门狗中断`
   - 状态寄存器TIMEOUT_BIT被置位

4. **测试4: 喂狗功能测试**
   - 控制台输出：`测试4: 喂狗功能测试`
   - 5ms时执行喂狗操作：`已执行喂狗操作，看门狗计数器已重置`
   - 等待15ms后无超时中断产生：`喂狗成功，未产生超时中断`

5. **测试5: 自动重载功能测试**
   - 控制台输出：`测试5: 自动重载功能测试`
   - 每5ms产生一次中断信号
   - 状态寄存器TIMEOUT_BIT周期性置位后自动清除

6. **测试6: 关闭看门狗**
   - 控制台输出：`测试6: 关闭看门狗`
   - 控制寄存器被设置为0x00
   - 不再产生中断和复位信号

**信号观察要点：**
- `wdt_interrupt`：约5ms时产生高电平脉冲，自动重载模式下每5ms重复
- `wdt_reset`：约5ms时产生高电平脉冲（如果启用）
- `status_reg[TIMEOUT_BIT]`：超时后置位为1，自动重载后清除

## 9. 风险评估

| 风险项 | 风险描述 | 应对措施 |
|-------|---------|---------|
| PWM时序问题 | PWM输出的周期和占空比与配置值不符 | 检查时钟频率配置和计数器实现 |
| 看门狗计时不准 | 实际超时时间与配置值偏差较大 | 校准1ms计时单元，检查时钟分频逻辑 |
| 寄存器访问错误 | 寄存器读写操作失败或数据错误 | 检查地址映射和总线接口实现 |
| 系统集成问题 | 新增外设影响现有系统功能 | 进行全面的回归测试，确保兼容性 |

## 10. 附录

### 10.1 测试程序示例

#### PWM测试程序片段

```c
// 配置PWM通道0，周期1ms，占空比50%
write32(PWM_BASE + PWM_CH0_REG, (1000 << 16) | 500);
// 使能PWM通道0
write32(PWM_BASE + PWM_CTRL_REG, 0x1);
```

#### 看门狗测试程序片段

```c
// 配置看门狗超时时间为1秒
write32(WDT_BASE + WDT_TIME_REG, 1000);
// 使能看门狗，启用中断和复位
write32(WDT_BASE + WDT_CTRL_REG, WDT_EN | WDT_INT_EN | WDT_RST_EN);
// 喂狗操作
write32(WDT_BASE + WDT_RESET_REG, 0x1);
```
